# 🐍 Jogo da Cobrinha (Snake Game) em Python

## 📌 Sobre o Projeto
Este é o clássico Jogo da Cobrinha (Snake) desenvolvido em Python. O projeto foi criado para treinar e consolidar conceitos fundamentais de programação orientada a eventos, manipulação de coordenadas bidimensionais (X, Y), detecção de colisão e estruturação de um *game loop* contínuo.

## 🛠️ Tecnologias Utilizadas
* Python 3
* Pygame (Biblioteca para criação de jogos e interfaces visuais)

## 🚀 Como testar o código
1. Tenha o Python instalado na sua máquina.
2. É necessário instalar a biblioteca Pygame. Abra o terminal e digite:

```bash
pip install pygame
Baixe o arquivo .py deste repositório.
Navegue até a pasta do projeto no terminal e rode o comando:
python snakegame.py
(Use as setas do teclado para movimentar a cobra. Pressione Q para sair ou R para reiniciar caso perca).
